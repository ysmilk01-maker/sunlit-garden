# 햇빛정원 · 식물의 두 번째 모습

[햇빛정원 v11 테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261013-11)

로그인 없이 실행하는 세로 화면 정원 게임입니다. 씨앗을 고르고 배치한 뒤, 7일 동안 수확하며 다음 정원으로 나아갑니다. 원래 캠페인에 식물 진화 선택을 추가한 테스트판입니다.

- **6종 식물에 12가지 진화**를 제공합니다. 해바라기·클로버·베리·라벤더·버섯·벌집마다 두 가지 모습을 선택할 수 있습니다.
- 새 진화 정원에서는 **1·3·5일 수확 후** 진화를 선택합니다. 식물의 추가 수확과 이웃 효과를 보고 배치를 바꿔 볼 수 있습니다.
- 처음 6종에서 최종 20종까지 씨앗이 열립니다. 정원은 4×4에서 최대 7×7로 커지며, 100단계 뒤에도 계속 이어집니다.
- 기존 단계 목표와 성장 보너스, 제안 새로고침, 미션·꽃잎·장식·별 기록을 유지합니다.
- 심기와 진화에 짧은 시각 피드백을 제공합니다. 모션 감소 설정에서는 이동 연출을 줄입니다.
- BGM **BEATWAVE · James K**, 효과음, 음악 크기 설정을 제공합니다. 첫 버튼을 누른 뒤 음악이 시작되며 기존 소리 설정을 유지합니다.
- 세로 화면 전용입니다. 가로로 돌리면 화면을 세우는 안내가 나타납니다. iPhone Safari는 진동을 지원하지 않습니다.

## 기존 진행 기록

기존 v9 진행 중인 정원은 이전 규칙 그대로 이어갑니다. 자동으로 새 게임을 시작하지 않습니다. **새 진화를 사용하려면 홈의 ‘진화 정원 시작’으로 현재 판을 새로 시작해야 합니다.** 별·꽃잎 등 누적 기록은 유지합니다.

진행은 해당 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터를 삭제하면 기록이 사라질 수 있습니다.

## 이전 실험

[한 방울의 정원 v10.1](https://ysmilk01-maker.github.io/sunlit-garden/droplet.html?v=20261013-10.1)은 4×4 화단에서 물길을 연결하던 별도 실험 기록으로 남아 있습니다. 현재 메인 게임과 저장 키를 구분하며, 이전 실험 파일과 진행 데이터를 유지합니다.

현재 개발 테스트판이며 앱 스토어 출시본이 아닙니다. 실제 iPhone Safari의 화면·저장·음향 동작은 실기기에서 별도 검증이 필요합니다. 재미·밸런스·구매 의향은 검증되지 않았으며, 특정 식물만 반복 배치하는 전략이 해결됐다고 주장하지 않습니다.

## 로컬 실행

이 저장소 폴더에서 Python 3으로 정적 서버를 실행합니다.

```sh
python -m http.server 8796 --bind 127.0.0.1
```

같은 컴퓨터에서 `http://127.0.0.1:8796/`을 엽니다. 다른 기기에서는 위 공개 테스트 링크를 사용합니다.

현재 화면은 `experience-app.mjs`, 진화 규칙은 `evolution-core.mjs`, 진화 그림은 `evolution-art.mjs`, 짧은 심기·진화 연출은 `garden-feedback.mjs`를 사용합니다. 기존 `campaign-core.mjs`와 이전 규칙 모듈은 저장 호환성을 위해 유지합니다.

원본 게임 로직과 디자인 및 오디오 자산은 나인투식스랩의 프로젝트 자산입니다. 별도 이용 허가를 부여하지 않습니다.
