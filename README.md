# 햇빛정원

[햇빛정원 v22 테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261018-22)

로그인 없이 실행하는 세로 화면 정원 게임입니다. 씨앗을 골라 빈 땅에 심고, 7일 동안 수확하며 다음 정원으로 나아갑니다. 현재 개발 테스트판입니다.

## v22 변경

- 주변 식물로 이어지는 연결선, 색 테두리, 영향 점수 배지와 영향 요약을 제거했습니다.
- 씨앗을 선택하면 기존 특성 설명을 볼 수 있습니다. 심어진 식물을 누르면 상세 설명이 열립니다.
- 날씨 배경, 3단계 진화, 실제 점수 계산과 저장 규칙은 유지합니다.

## 게임과 진행 기록

정원은 4×4에서 최대 7×7로 커지고 100단계 이후에도 이어집니다. 6종 식물의 12가지 진화 갈래는 버전 6으로 시작한 정원에서 3단계까지 키울 수 있습니다. 버전 2–5로 시작한 정원은 당시 규칙으로 이어집니다.

진행과 설정은 해당 브라우저에 저장됩니다. 브라우저 데이터를 지우면 기록이 사라질 수 있으며 기기 간 동기화는 제공하지 않습니다. BGM **BEATWAVE · James K**는 첫 버튼을 누른 뒤 시작합니다.

## 확인 범위

자동 회귀 검사 13개와 구문 검사를 통과했습니다. 로컬 Chrome에서 320×568·390×844 화면의 가이드 제거, 씨앗 설명, 심기, 되돌리기, 기존 식물 상세와 화면 넘침 여부를 확인했습니다. 실제 iPhone Safari 및 실기기 성능·청취는 아직 확인하지 않았습니다.

세로 화면 전용이며 가로 화면에는 회전 안내가 나타납니다. iPhone Safari의 진동은 지원하지 않습니다.
