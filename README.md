# 햇빛정원 · 주변 효과가 보이는 정원

[햇빛정원 v21 테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261015-21)

로그인 없이 실행하는 세로 화면 정원 게임입니다. 씨앗을 비교해 빈 땅에 심고, 7일 동안 수확하며 다음 정원으로 나아갑니다. 현재 개발 테스트판입니다.

## v21 주변 식물 영향 표시

- 씨앗을 고르면 수확 변화가 가장 큰 기준 자리를 금빛으로 표시합니다. 그 자리에 심었을 때 다른 식물에서 늘거나 줄어드는 점수가 연결선과 배지로 나타납니다.
- 마우스 포인터나 키보드 초점을 다른 빈칸으로 옮기면 그 자리의 효과를 미리 확인합니다. 빈칸을 한 번 눌러 바로 심는 조작은 유지합니다.
- 심은 뒤나 기존 식물을 누르면 그 식물이 다른 식물에 주는 영향을 보여 줍니다. **청록 +**는 증가, **분홍 −**는 감소, **노랑 ±0**은 서로 다른 효과가 상쇄된 경우입니다.
- 상하좌우뿐 아니라 같은 열·행·정원 전체 효과로 달라지는 식물도 포함합니다. 확대 구역 밖의 대상은 전체 정원과 영향 요약에서 확인합니다.
- 배지는 식물의 전체 수확 점수가 아닌 **이번 선택에 따른 변화량**입니다. 기존 식물은 그 식물이 없는 가상 정원과 현재 정원을 비교합니다. 삭제 기능이나 추가 점수 보상이 아니며, 여러 식물의 영향 합계를 더해 정원 총점으로 사용할 수 없습니다.
- 표시를 바꾸거나 닫아도 게임 상태는 바뀌지 않습니다. 점수·씨앗 제안·진화·날씨·저장 엔진은 v20 그대로입니다.

## 유지되는 게임

- 처음 6종에서 최종 20종까지 씨앗이 열리며, 정원은 4×4에서 최대 7×7로 커집니다. 100단계 뒤에도 계속 이어집니다.
- 6종 식물의 12가지 진화 갈래를 3단계까지 키웁니다. 1·3·5일 수확 후 진화 기회를 사용합니다.
- 맑음·비·흐림 배경과 2·4·6일 날씨 부탁, 꽃잎·장식·별 기록을 유지합니다. 홈·숨겨진 탭에서 날씨 연출을 멈추고 모션 줄이기 설정을 따릅니다.
- 처음 만난 씨앗 소개는 **확인**한 것만 같은 브라우저에 읽음으로 저장합니다. 나중에 보기·닫기·Escape는 읽음 처리하지 않습니다.
- BGM **BEATWAVE · James K**, 효과음과 음악 크기·음소거 설정을 유지합니다. 음악은 첫 버튼을 누른 뒤 시작합니다.

## 진행 기록과 검증 범위

기존 버전 2–5의 진행은 당시 규칙 그대로 이어갑니다. 3단계 진화는 버전 6으로 시작한 정원부터 적용됩니다. 홈의 **‘3단계 진화 정원 새로 시작’**은 현재 정원을 새로 시작하며 누적 기록과 도감은 유지합니다.

진행과 설정은 해당 브라우저에 저장됩니다. 브라우저 데이터를 지우면 기록이 사라질 수 있고 기기 간 동기화는 제공하지 않습니다.

자동 테스트 44개와 수정 후 로컬 브라우저 화면 검사 12회를 통과했습니다. 320×568·390×844 화면, 영향 표시·심기·되돌리기·확대·저장 보존을 확인했습니다. 공개 배포는 같은 커밋의 Pages 빌드와 원본·Git·공개 파일 해시를 대조합니다.

**실제 iPhone Safari, 실기기 성능·청취, 사람의 재미와 체감 난도는 미검증입니다.** 세로 화면 전용이며 가로 화면에는 회전 안내가 나타납니다. iPhone Safari의 진동은 지원하지 않습니다.

## 이전 실험과 로컬 실행

[한 방울의 정원 v10.1](https://ysmilk01-maker.github.io/sunlit-garden/droplet.html?v=20261013-10.1)은 별도 물길 연결 실험으로 보존합니다. 메인 게임과 저장 키가 다릅니다.

Python 3이 설치된 환경에서 이 저장소 폴더를 열고 실행합니다.

```sh
python -m http.server 8796 --bind 127.0.0.1
```

같은 컴퓨터에서 http://127.0.0.1:8796/ 를 엽니다. 다른 기기는 위 공개 HTTPS 링크를 사용합니다.

게임·디자인·오디오 자산은 나인투식스랩의 프로젝트 자산입니다. 별도 이용 허가를 부여하지 않습니다.
