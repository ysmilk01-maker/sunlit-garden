# 햇빛정원

[햇빛정원 v23 테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261018-23)

로그인 없이 실행하는 세로 화면 정원 게임입니다. 씨앗을 골라 빈 땅에 심고, 7일 동안 수확하며 다음 정원으로 나아갑니다. 현재 개발 테스트판입니다.

## v23 변경

- 화면과 아이콘을 정리하고, 진행 상태에 따라 시작 화면에 이어하기·다음 정원·재도전을 표시합니다.
- 일시정지 화면에서 현재 진행을 확인하고 수확 기록·설정·시작 화면으로 이동할 수 있습니다.
- 결과 화면에 가장 많이 수확한 날과 식물, 다음 목표를 정리했습니다.
- 기기 저장 상태를 표시하고 이전 JSON 저장본을 보관합니다. JSON을 읽지 못하면 사용 가능한 백업으로 복구하며, 손상된 원문도 가능한 경우 별도로 보존합니다. 모든 종류의 손상 복구를 보장하지는 않습니다.

주변 영향 연결선·배지는 계속 표시하지 않습니다. 씨앗 특성 설명과 심어진 식물의 상세 설명은 유지하며 점수 계산·날씨·진화 규칙은 바꾸지 않았습니다.

## 진행 기록

진행과 설정은 해당 브라우저에 저장됩니다. 브라우저 데이터를 지우면 기록이 사라질 수 있으며 기기 간 동기화는 제공하지 않습니다. 저장 공간에 문제가 있으면 화면 안내를 확인해 주세요.

버전 2–5로 시작한 정원은 당시 규칙으로 이어집니다. 3단계 진화는 버전 6으로 시작한 정원에서 적용됩니다. BGM **BEATWAVE · James K**는 첫 버튼을 누른 뒤 시작합니다.

## 확인 범위

자동 검사 32개와 구문 검사를 통과했습니다. 로컬 Chrome의 320×568·390×844 화면에서 화면 넘침, 버튼 잘림, 이미지 로딩, 이어하기·재도전·일시정지·결과·확대·저장 복구를 확인했습니다. 실제 iPhone Safari 및 실기기 성능·청취는 아직 확인하지 않았습니다.

세로 화면 전용이며 가로 화면에는 회전 안내가 나타납니다. iPhone Safari의 진동은 지원하지 않습니다.
