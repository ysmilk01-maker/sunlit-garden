# 햇빛정원 · 식물의 두 번째 모습

[햇빛정원 v18 테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261014-18)

로그인 없이 실행하는 세로 화면 정원 게임입니다. 씨앗을 고르고 배치한 뒤, 7일 동안 수확하며 다음 정원으로 나아갑니다. 원래 캠페인에 식물 진화 선택을 추가한 테스트판입니다.

- **6종 식물에 12가지 진화**를 제공합니다. 해바라기·클로버·베리·라벤더·버섯·벌집마다 두 가지 모습을 선택할 수 있습니다.
- 새 진화 정원에서는 **1·3·5일 수확 후** 진화를 선택합니다. 식물의 추가 수확과 이웃 효과를 보고 배치를 바꿔 볼 수 있습니다.
- 처음 6종에서 최종 20종까지 씨앗이 열립니다. 정원은 4×4에서 최대 7×7로 커지며, 100단계 뒤에도 계속 이어집니다.
- 기존 단계 목표와 성장 보너스, 제안 새로고침, 미션·꽃잎·장식·별 기록을 유지합니다.
- 심기와 진화에 짧은 시각 피드백을 제공합니다. 모션 감소 설정에서는 이동 연출을 줄입니다.
- BGM **BEATWAVE · James K**, 효과음, 음악 크기 설정을 제공합니다. 첫 버튼을 누른 뒤 음악이 시작되며 기존 소리 설정을 유지합니다.
- 세로 화면 전용입니다. 가로로 돌리면 화면을 세우는 안내가 나타납니다. iPhone Safari는 진동을 지원하지 않습니다.

## v18 색상과 시각 효과

정원 화면의 색상을 짙은 청록·금빛 중심으로 바꾸고, 심기·진화·수확·성장 선택의 시각 피드백을 보강했습니다. 기존 점수 코어·성장 규칙·저장·이미지·음원은 유지합니다. 모션 감소 설정과 화면을 숨길 때의 연출 정리를 지원합니다.

**v18 브라우저 화면과 실제 모바일·iPhone 동작은 검증하지 못했습니다.** 이번 작업에서는 브라우저 연결을 사용할 수 없어 코드·자동 테스트 및 공개 파일 전달 상태를 확인했습니다. 이전 v17 화면 검사 결과를 v18 검사 결과로 간주하지 않습니다.

## 화면에서 바로 보는 선택 효과

씨앗을 선택하면 별도 팝업 없이 정원 화면에서 특성을 확인하고 바로 심을 수 있습니다. 점수 계산·성장 규칙·저장·음원은 유지합니다.

- 씨앗 카드에는 기본 수확, 추가 점수의 조건, 현재 정원에서의 오늘 최대 점수 변화를 표시합니다.
- 선택한 씨앗의 특성과 현재 판에서 적용되는 설명을 화면 안에 보여 줍니다. 확대 정원에서도 씨앗을 비교하고 바로 배치할 수 있습니다.
- 새 식물의 수확과 기존 식물들의 증감을 나누어 설명합니다. 정원 전체 변화는 두 항목의 합이며, 현재 판의 이번 수확 기준입니다.
- **정원의 힘** 각 카드에 능력의 기본 효과를 먼저 표시합니다. 카드를 누르면 내 정원의 예상 변화가 나오며, 다른 능력과 비교한 뒤 선택을 확정합니다.
- 예상값은 표시된 배치와 조건에 따른 계산입니다. 다른 칸이나 이후 날의 결과는 달라질 수 있습니다.

## 온실과 정원 화면

온실 시작 화면과 화단 중심의 게임 화면을 적용했습니다. 기존 성장 규칙·점수·단계 목표·저장 기록·음향 설정은 유지합니다.

- 기본 6종과 진화 12종을 같은 클레이 스타일의 이미지로 보여 줍니다. 우물과 공통 새싹 이미지도 추가했습니다. 성장 단계는 크기와 이름표로 구분하며, 이미지를 불러오지 못하면 원래 SVG 그림으로 복구합니다.
- 씨앗 3개를 계속 비교하며 선택할 수 있습니다. 선택한 씨앗을 놓을 때의 이번 수확 점수 변화와 가장 높은 자리를 표시합니다. 표시값은 현재 판의 예상값이며 다음 날의 최선 배치를 보장하지 않습니다.
- 목표까지 남은 점수와 진행 정도를 정원 화면에서 확인합니다.
- 수확할 때마다 반드시 닫아야 했던 상세 보고창을 없앴습니다. 수확 연출 뒤 진화·성장 보너스·다음 날 등 다음 행동으로 이어지고, 상세 내역은 정원 기록의 ‘지난 수확 자세히’에서 열 수 있습니다.

## 선택 설명과 소리

게임 규칙과 단계 목표, 기존 진행 기록을 바꾸지 않고 선택에 필요한 정보와 소리를 추가했습니다.

- 씨앗·강화·진화 화면에서 현재 판을 기준으로 계산한 점수 변화, 발동 조건, 다음 배치 설명을 확인합니다. 예상 점수는 표시된 배치·날씨·수확 시점 등의 조건에 따른 계산값입니다.
- 강화·진화는 선택지를 비교한 뒤 확정합니다. 비교하거나 정확한 규칙을 읽는 것만으로 정원 상태가 바뀌지 않습니다.
- 선택·정보 확인·심기·수확·개화·진화·강화·다시 뽑기·되돌리기·미션·성공·목표 미달의 효과음 **12종**을 제공합니다.
- 기존 음소거 설정을 유지합니다. 홈의 효과음 버튼으로 켜거나 끌 수 있고, 설정 화면에서 효과음을 미리 들을 수 있습니다. 배경음악과 효과음은 각각 설정합니다.

## 기존 진행 기록

기존 v9 진행 중인 정원은 이전 규칙 그대로 이어갑니다. 자동으로 새 게임을 시작하지 않습니다. **새 진화를 사용하려면 홈의 ‘진화 정원 시작’으로 현재 판을 새로 시작해야 합니다.** 별·꽃잎 등 누적 기록은 유지합니다.

진행은 해당 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터를 삭제하면 기록이 사라질 수 있습니다.

## 이전 실험

[한 방울의 정원 v10.1](https://ysmilk01-maker.github.io/sunlit-garden/droplet.html?v=20261013-10.1)은 4×4 화단에서 물길을 연결하던 별도 실험 기록으로 남아 있습니다. 현재 메인 게임과 저장 키를 구분하며, 이전 실험 파일과 진행 데이터를 유지합니다.

현재 개발 테스트판이며 앱 스토어 출시본이 아닙니다. 실제 iPhone Safari의 화면·저장·음향 동작은 실기기에서 별도 검증이 필요합니다. 재미·밸런스·구매 의향은 검증되지 않았으며, 특정 식물만 반복 배치하는 전략이 해결됐다고 주장하지 않습니다.

## 로컬 실행

이 저장소 폴더에서 Python 3으로 정적 서버를 실행합니다.

```sh
python -m http.server 8796 --bind 127.0.0.1
```

같은 컴퓨터에서 `http://127.0.0.1:8796/`을 엽니다. 다른 기기에서는 위 공개 테스트 링크를 사용합니다.

현재 화면은 `experience-app.mjs`와 `atelier.css`, v18 색상과 효과 스타일은 `festival.css`와 `festival-effects.css`, 목표와 배치 강조 표시 보조 함수는 `garden-journey.mjs`, 진화 규칙은 `evolution-core.mjs`, 이미지 연결과 복구는 `garden-sprites.mjs`, 기존 진화 그림은 `evolution-art.mjs`, 짧은 심기·진화 연출은 `garden-feedback.mjs`를 사용합니다. 씨앗 점수 설명은 `seed-explainer.mjs`, 씨앗·능력 효과 문구는 `choice-copy.mjs`, 선택 화면 스타일은 `seed-choice.css`, 강화·진화 설명은 `garden-strategy.mjs`, 효과음은 `garden-audio.mjs`를 사용합니다. 기존 `campaign-core.mjs`와 이전 규칙 모듈은 저장 호환성을 위해 유지합니다.

원본 게임 로직과 디자인 및 오디오 자산은 나인투식스랩의 프로젝트 자산입니다. 별도 이용 허가를 부여하지 않습니다.
