로그인 없이 즐기는 세로 화면 정원 게임입니다. 씨앗을 골라 배치하고, 7일 동안 식물을 키우며 수확 목표에 도전합니다. 현재 개발 테스트판입니다.

## v24 변경

- 새 정원에서는 한 판에 한 번 식물을 빈칸으로 옮겨 심을 수 있습니다. 성장과 진화는 그대로 유지하며, 확정 전에 오늘·다음 수확 변화를 비교할 수 있습니다.
- 씨앗의 기본 효과와 다음 수확 예고를 함께 살펴보고, 즉시 수확과 장기 성장을 선택할 수 있습니다.
- 수확 연출이 실제 이웃 효과와 진화 추가 수확을 보여 줍니다. 화면을 벗어나거나 동작 줄이기를 선택하면 연출 대기를 줄입니다.
- 씨앗 선택, 되돌리기, 수확, 결과의 안내와 피드백을 다듬었습니다.

주변 영향 연결선·범위 가이드는 표시하지 않습니다. 7일 진행, 단계별 정원 크기, 날씨, 같은 열 보너스와 3단계 진화를 유지합니다.

## 진행 기록과 호환

진행과 설정은 해당 브라우저에 저장됩니다. 브라우저 데이터를 지우면 기록이 사라질 수 있으며 기기 간 동기화는 제공하지 않습니다. 저장 공간에 문제가 있으면 화면의 저장 상태를 확인해 주세요.

버전 2–6으로 시작한 정원은 기존 규칙으로 이어집니다. 옮겨심기는 새로 시작하는 버전 7 정원에서 제공됩니다. 기존 정원의 점수·목표·진화 규칙을 소급 변경하지 않습니다.

BGM **BEATWAVE · James K**는 첫 버튼을 누른 뒤 시작합니다.
