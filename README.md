# 햇빛정원 · 백 개의 정원

[아이폰 Safari에서 테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261013-5)

로그인 없이 실행하는 개발 중인 정원 캠페인 게임입니다.

- 100개 단계를 순서대로 진행하며 각 단계의 최소 점수 목표에 도전합니다.
- 12종 식물과 시설, 날씨와 이웃 조합을 활용합니다.
- 단계가 진행되면 정원이 4×4에서 최대 7×7로 확장됩니다.
- 세로 화면 전용입니다. 휴대폰을 가로로 돌리면 세로 전환 안내를 표시합니다.
- 진행 기록은 해당 브라우저의 로컬 저장소에 저장됩니다.

현재 테스트판이며 유료 완제품이나 앱 스토어 출시본이 아닙니다. 실제 아이폰 Safari의 전체 동작과 100단계의 재미·난이도는 추가 검증 대상입니다.

## 로컬 실행

이 저장소 폴더에서 Python 3으로 정적 서버를 실행합니다.

```sh
python -m http.server 8796 --bind 127.0.0.1
```

같은 컴퓨터의 브라우저에서 `http://127.0.0.1:8796/`을 엽니다. 다른 기기에서는 위 공개 테스트 링크를 사용합니다.

현재 화면은 `campaign-app.mjs`, 규칙은 `campaign-core.mjs`를 사용합니다. 이전 버전 모듈은 기록과 공유 데이터 의존성을 위해 유지합니다.

원본 게임 로직과 디자인은 나인투식스랩의 프로젝트입니다. 별도 이용 허가를 부여하지 않습니다.
