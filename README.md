# 햇빛정원 · 끝없이 자라는 정원

[아이폰 Safari에서 테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261013-9)

로그인 없이 실행하는 개발 중인 세로 화면 정원 게임입니다.

- 최소 점수 목표를 넘기며 정원을 계속 이어갑니다. 처음 6종에서 최종 20종의 씨앗을 만나며 정원은 4×4에서 최대 7×7로 커집니다.
- 같은 세로열에 같은 식물을 모으면 각각 추가 점수를 받습니다. 2개는 +2점씩, 3개는 +4점씩, 4개 이상은 +6점씩이며 서로 붙어 있지 않아도 됩니다. 우물·벌집은 제외합니다.
- v9의 1~100단계 목표는 v8보다 약 20% 높은 475~2,290점입니다. 101단계부터도 새 씨앗·날씨·우물 배치의 7×7 정원이 계속 생성됩니다. 목표는 판 조건에 따라 오르내리며, 자동 플레이로 확인한 달성 가능한 점수를 반영해 보정합니다.
- 클로버 이웃 보너스는 최대 둘까지만 적용하며, 다양한 식물 배치를 돕는 성장 보너스를 활용할 수 있습니다.
- 2·4·6일 성장 보너스 선택마다 제안 3개 전체를 무료로 한 번 새로 뽑을 수 있습니다. 사용한 재추첨 횟수도 저장됩니다.
- 기존 v2·v3 진행 중인 정원은 이전 규칙으로 이어갑니다. 홈의 새 규칙 시작 버튼으로 현재 단계를 새로 시작할 수 있으며, 클리어·최고점·별·꽃잎·장식 기록은 유지합니다. 기존 100단계 완료 기록은 101단계를 엽니다.
- 토끼 모모가 게임 속 2·4·6일에 미션을 제안합니다. 같은 단계·같은 날 미션 첫 해결 시 꽃잎 2개, 단계 첫 클리어 시 꽃잎 3개를 받습니다.
- 꽃잎으로 장식 4종을 열고 정원에 적용합니다. 장식을 적용해도 꽃잎은 줄지 않습니다.
- 단계별 별 평가와 수집 기록을 확인합니다. 기존 캠페인 기록은 새 프로필에 반영합니다.
- BGM **BEATWAVE · James K**가 반복 재생됩니다. 첫 화면은 무음이며 버튼을 누른 뒤 재생을 시작합니다.
- 음악과 효과음을 각각 켜고 끌 수 있고 음악 음량도 조절합니다. 설정은 브라우저에 저장됩니다.
- 진동 설정을 제공합니다. iPhone Safari는 진동을 지원하지 않습니다.
- 세로 화면 전용입니다. 휴대폰을 가로로 돌리면 세로 전환 안내를 표시합니다.
- 진행 기록은 해당 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다.

현재 테스트판입니다. 실제 iPhone Safari의 전체 화면·저장·음향 동작은 실기기에서 별도 검증이 필요합니다. 유료 완제품이나 앱 스토어 출시본이 아니며, 재미·난이도·구매 의향 역시 추가 검증 대상입니다.

## 로컬 실행

이 저장소 폴더에서 Python 3으로 정적 서버를 실행합니다.

```sh
python -m http.server 8796 --bind 127.0.0.1
```

같은 컴퓨터의 브라우저에서 `http://127.0.0.1:8796/`을 엽니다. 다른 기기에서는 위 공개 테스트 링크를 사용합니다.

현재 화면은 `experience-app.mjs`, 미션·장식·별 기록은 `garden-features.mjs`, 캠페인 규칙은 `campaign-core.mjs`, BGM 제어는 `garden-music.mjs`를 사용합니다. `campaign-legacy-v7.mjs`와 `campaign-legacy-v8.mjs`는 기존 정원을 이어가는 데 사용합니다. 이전 모듈은 기록과 공유 데이터 의존성을 위해 유지합니다.

원본 게임 로직과 디자인 및 오디오 자산은 나인투식스랩의 프로젝트 자산입니다. 별도 이용 허가를 부여하지 않습니다.
