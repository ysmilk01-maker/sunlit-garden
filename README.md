# 햇빛정원 · 한 방울의 정원

[새 실험판 플레이 — 로그인 없이 열기](https://ysmilk01-maker.github.io/sunlit-garden/droplet.html?v=20261013-10.1)

씨앗으로 물길을 연결하고, 한 방울로 꽃을 피우는 세로 화면 정원 게임입니다. v10.1은 **4×4 화단·식물 4종·정원 3개**로 핵심 재미를 확인하는 첫 실험입니다.

- 씨앗을 두 번까지 심고, 위쪽에서 물을 줄 세로열 하나를 고릅니다. 점선으로 물길을 미리 확인할 수 있습니다.
- 해바라기는 물을 아래로, 민트는 좌우로 보냅니다. 딸기는 두 번 익으면 수확되어 빈칸이 되고, 벌집은 옆 꽃이 피면 가까운 딸기로 벌을 보냅니다.
- 수확한 자리에 다시 심어 물길을 바꿀 수 있습니다. 심기 되돌리기와 연쇄 바로 보기를 제공합니다.
- 씨앗을 심을 때 짧은 심기 연출이 나타납니다. 모션 감소 설정에서는 이동 연출을 줄입니다.
- 선택·심기·물주기·개화·벌·성장·수확·되돌리기·성공·목표 미달의 효과음 10종을 제공합니다. 설정의 ▶ 버튼으로 미리 들을 수 있으며, 기존에 꺼 둔 효과음 설정도 유지합니다.
- 진행은 해당 브라우저에 저장합니다. 브라우저 데이터를 삭제하면 기록이 사라질 수 있습니다.
- BGM **BEATWAVE · James K**와 효과음, 음악 크기 설정을 제공합니다. 첫 버튼을 누른 뒤 음악이 시작됩니다.
- 세로 화면 전용입니다. 가로로 돌리면 화면을 세우는 안내가 나타납니다. 모션 감소 설정을 지원하며, iPhone Safari는 진동을 지원하지 않습니다.

**변이·계승 시스템은 후속 검토 항목이며 이번 실험판에는 없습니다.** 재미·난이도·구매 의향을 확인하는 테스트판으로, 앱 스토어 출시본이 아닙니다. 실제 iPhone Safari의 화면·저장·음향 동작은 실기기에서 별도 검증이 필요합니다.

## 기존 햇빛정원

[기존 v9 캠페인 이어하기](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261013-9)

기존 20종 식물·성장 보너스·장식·무한 단계 캠페인은 별도 화면으로 유지합니다. 두 게임의 진행 저장 키를 구분하여 기존 기록을 보존합니다. 새 실험판에서 기존 캠페인으로 돌아갈 수 있습니다.

## 로컬 실행

이 저장소 폴더에서 Python 3으로 정적 서버를 실행합니다.

```sh
python -m http.server 8796 --bind 127.0.0.1
```

같은 컴퓨터에서 `http://127.0.0.1:8796/droplet.html`을 엽니다. 다른 기기에서는 위 공개 테스트 링크를 사용합니다.

새 실험판은 `droplet.html`, `droplet.css`, `droplet-app.mjs`, `droplet-core.mjs`, `droplet-audio.mjs`를 사용합니다. 그림과 오디오 자산은 기존 게임과 공유합니다. 이전 캠페인 모듈은 저장 호환성을 위해 유지합니다.

원본 게임 로직과 디자인 및 오디오 자산은 나인투식스랩의 프로젝트 자산입니다. 별도 이용 허가를 부여하지 않습니다.
