# 햇빛정원 · 일곱 날의 정원

[아이폰 Safari에서 테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261013-4)

로그인 없이 실행하는 개발 중인 성장형 정원 게임입니다.

- 6종 씨앗 중 제안받은 3종을 골라 4×4 정원에 하루 두 번 심습니다.
- 오늘·내일 날씨와 이웃 식물 조합을 고려해 7일 동안 정원을 키웁니다.
- 수확 뒤에도 식물이 남아 성장하며, 2·4·6일 수확 뒤 보너스를 선택합니다.
- 300·400·500·600점에 도전합니다. 시간 제한은 없습니다.
- 세로 화면 전용입니다. 가로 화면에서는 세로 전환 안내를 표시합니다.
- 진행 기록은 해당 브라우저의 로컬 저장소에 저장됩니다. 이전 빛 퍼즐 저장 기록은 덮어쓰지 않습니다.

## 검증 범위

개발 환경에서 핵심 로직 19개 테스트, 7일 완주·저장·회전 안내·모바일 화면 배치를 확인했습니다. 실제 아이폰 Safari 전체 동작 및 재미·구매 의향은 별도 검증이 필요합니다. 현재 앱 스토어 출시본이나 유료 완제품이 아닙니다.

## 로컬 실행

이 저장소 폴더에서 Python 3으로 정적 서버를 실행합니다.

```sh
python -m http.server 8796 --bind 127.0.0.1
```

같은 컴퓨터의 브라우저에서 `http://127.0.0.1:8796/`을 엽니다. 다른 기기에서 테스트할 때는 위 공개 테스트 링크를 사용합니다.

`core.mjs`, `levels.mjs`는 이전 빛 퍼즐 기록이며 현재 성장형 게임은 `growth-core.mjs`, `garden-art.mjs`를 사용합니다.

원본 게임 로직과 디자인은 나인투식스랩의 프로젝트입니다. 별도 이용 허가를 부여하지 않습니다.
