# 햇빛정원

[햇빛정원 v25 테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261020-25)

로그인 없이 즐기는 세로 화면 정원 게임입니다. 씨앗을 골라 배치하고, 7일 동안 식물을 키우며 수확 목표에 도전합니다. 현재 개발 테스트판입니다.

## v25 변경

- 시작 화면에 배너 광고 자리를 추가했습니다.
- 결과 화면에 선택형 보상 광고 자리를 추가했습니다. 다음 정원과 다시 도전은 광고를 선택하지 않아도 이용할 수 있습니다.
- 두 자리의 미리보기를 누르면 별도 예시 화면이 열립니다. 닫기나 돌아가기 버튼으로 즉시 닫을 수 있습니다.

광고 SDK와 광고 네트워크 요청은 연결하지 않았습니다. 실제 광고를 재생하거나 광고 보상을 지급하지 않습니다. 광고 미리보기로 점수·꽃잎·진행 기록이 바뀌지 않습니다.

심기·진화·수확 중에는 광고를 표시하지 않습니다. 7일 진행, 단계별 정원 크기, 날씨, 같은 열 보너스, 3단계 진화와 옮겨심기를 유지합니다. 주변 영향 연결선·범위 가이드는 표시하지 않습니다.

## 진행 기록과 호환

진행과 설정은 해당 브라우저에 저장됩니다. 브라우저 데이터를 지우면 기록이 사라질 수 있으며 기기 간 동기화는 제공하지 않습니다. 저장 공간에 문제가 있으면 화면의 저장 상태를 확인해 주세요.

버전 2–6으로 시작한 정원은 기존 규칙으로 이어집니다. 옮겨심기는 새로 시작하는 버전 7 정원에서 제공됩니다. 기존 정원의 점수·목표·진화 규칙을 소급 변경하지 않습니다.

BGM **BEATWAVE · James K**는 첫 버튼을 누른 뒤 시작합니다.

## 확인 범위

자동 검사 31개를 통과했습니다. 로컬 Chrome의 320×568·390×844 화면에서 광고 자리와 미리보기 조작을 확인했습니다. 실제 iPhone Safari 및 실기기 성능·청취는 아직 확인하지 않았습니다.

세로 화면 전용이며 가로 화면에는 회전 안내가 나타납니다. iPhone Safari의 진동은 지원하지 않습니다.
