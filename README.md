# 햇빛정원 — v29 자유 가꾸기

[테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261026-29)

7일 동안 씨앗을 배치하고 수확하는 세로 화면 정원 게임입니다. 개발 테스트판입니다.

- 안 쓴 씨앗은 보관합니다. 하루 한 번 원하는 종류로 교환할 수 있습니다.
- 하루 행동을 심기·돌보기·옮기기·비우기에 나누어 씁니다. 각각 1행동입니다.
- 식물을 누르면 관리할 수 있습니다. 남은 행동을 포기하고 먼저 수확할 수도 있습니다.
- 카드에는 역할과 조건을 먼저 표시합니다. 가꾸기 → 자리별 점수 보기에서 계산을 켭니다.
- 기존 진행은 원래 규칙으로 이어집니다. 새 기능은 홈의 ‘자유롭게 가꾸는 새 정원 시작’에서 체험하세요. 현재 판만 새로 시작하며 완료 기록은 보존됩니다.

자동 검사 372개 통과. Chrome 320×568·390×844 화면과 신규 조작 확인. 실제 아이폰 Safari 및 사람의 재미 평가는 확인 못 함.
기록은 이 브라우저에 저장합니다. 실제 광고·결제는 연결하지 않았습니다. 배경음악은 기존 Web Audio 연주곡입니다.
게임·디자인·음악 자산은 나인투식스랩 프로젝트 자산이며 별도 이용 허가를 부여하지 않습니다.
