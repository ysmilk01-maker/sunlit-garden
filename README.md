# 햇빛정원 · 날씨와 3단계 진화

[햇빛정원 v20 테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261015-20)

로그인 없이 실행하는 세로 화면 정원 게임입니다. 제안된 씨앗 3종을 비교해 빈 땅에 심고, 7일 동안 수확하며 다음 정원으로 나아갑니다. 현재 개발 테스트판이며 앱 스토어 출시본이 아닙니다.

## v20 변경 사항

- **오늘 날씨가 배경에 반영됩니다.** 맑은 날에는 따뜻한 햇살, 비 오는 날에는 빗줄기와 물결, 흐린 날에는 구름이 나타납니다. 수확 중에는 그날 날씨를 유지하고 다음 날로 넘어갈 때 바뀝니다.
- 홈과 숨겨진 탭에서는 날씨 애니메이션을 멈춥니다. 모션 줄이기 설정에서는 정적인 날씨 표현을 사용합니다.
- **6종 식물의 기존 12개 진화 갈래를 3단계까지 키울 수 있습니다.** 해바라기·클로버·베리·라벤더·버섯·벌집이 대상입니다. 다른 14종에는 이번 버전에서 새 진화를 추가하지 않았습니다.
- 1·3·5일 수확 후 진화 기회 하나를 사용해 일반 식물을 2단계로 만들거나, 2단계 식물을 같은 갈래의 3단계로 키웁니다. 진화 기회는 늘리지 않아 한 식물에 집중할지 여러 식물을 키울지 선택합니다.
- 진화 선택 화면에서 현재 식물과 비교한 다음 이틀의 예상 증가량과 발동 조건을 확인합니다. 3단계에는 기존 그림에 계열별 장식·금빛 테두리·✦3 표시를 더했습니다.
- **2·4·6일 날씨 부탁**은 오늘 날씨 보너스를 받는 씨앗을 현재 제안에서 고릅니다. 해당 씨앗이 없으면 기존 미션을 사용합니다. 보상은 기존 꽃잎 2개이며 별도 점수 보상은 없습니다.
- 날씨 부탁은 씨앗을 고르기 전에 안내 영역에 표시합니다. 씨앗을 고르면 해당 씨앗의 특성과 점수 설명으로 바뀝니다.

## 기존 진행과 새 정원

기존 버전 2–5의 진행은 **당시 규칙 그대로** 이어집니다. 과거 저장의 버전만 바꾸거나 점수를 새 규칙으로 다시 계산하지 않습니다.

새 진화는 엔진 버전 6으로 시작한 정원부터 적용됩니다. 진행 중인 정원을 바꾸려면 홈의 **‘3단계 진화 정원 새로 시작’**을 선택합니다. 현재 정원은 새로 시작하며, 누적 기록과 도감은 유지합니다.

진행·설정·처음 만난 씨앗의 읽음 상태는 해당 브라우저에 저장됩니다. 브라우저 데이터를 삭제하면 기록이 사라질 수 있으며 기기 간 동기화는 제공하지 않습니다.

## 계속 유지되는 기능

- 처음 6종에서 최종 20종까지 씨앗이 열립니다. 정원은 4×4에서 최대 7×7까지 커지며 100단계 뒤에도 계속 이어집니다.
- 기존 목표 점수, 같은 세로열 보너스, 정원의 힘과 제안 새로고침, 미션·꽃잎·장식·별 기록을 유지합니다.
- 씨앗을 비교하면 기본 수확·조건·이번 수확의 예상 점수 변화를 화면 안에서 확인하고 바로 심을 수 있습니다. 예상값은 현재 배치와 조건을 기준으로 하며 미래의 최선 배치를 보장하지 않습니다.
- 정원을 시작할 때 처음 만난 씨앗을 소개합니다. **확인**한 씨앗만 읽음으로 저장하며 다음 라운드에는 새로 열린 씨앗만 보여 줍니다. **나중에 보기·닫기(X)·Escape**는 읽음 처리하지 않습니다.
- BGM **BEATWAVE · James K**, 효과음 12종, 음악 크기 설정과 기존 음소거 설정을 유지합니다. 음악은 첫 버튼을 누른 뒤 시작합니다.
- 식물 그림을 불러오지 못하면 SVG로 복구합니다. 심기·진화·수확에 짧은 시각 피드백을 제공합니다.
- 세로 화면 전용입니다. 가로 화면에서는 세워 달라는 안내가 나타납니다. iPhone Safari의 진동은 지원하지 않습니다.

## 검증 범위

자동 테스트와 로컬 브라우저에서 날씨 3종, 진화 비교·확정·결과, 기존 저장 유지, 320×568·390×844 화면과 날씨 부탁 안내를 검사했습니다. 공개 배포에서는 같은 커밋의 Pages 빌드와 원본·Git·공개 파일의 SHA256 일치를 확인합니다.

**실제 iPhone Safari, 실기기 발열·프레임·청취는 검증하지 않았습니다.** 사람의 반복 플레이 재미와 체감 난도·구매 의향도 미검증입니다. 기존 목표 점수를 유지했으므로 3단계 진화가 난도에 미치는 영향은 추가 플레이 평가가 필요합니다.

## 로컬 실행

Python 3이 설치된 환경에서 이 저장소 폴더를 열고 다음 명령을 실행합니다.

```sh
python -m http.server 8796 --bind 127.0.0.1
```

같은 컴퓨터에서 http://127.0.0.1:8796/ 를 엽니다. 다른 기기에서는 위 공개 HTTPS 테스트 링크를 사용합니다.

게임·디자인·오디오 자산은 나인투식스랩의 프로젝트 자산입니다. 별도 이용 허가를 부여하지 않습니다.
