## v26 음악 변경

- 배경음악은 짧은 BEATWAVE 연주곡을 Web Audio 버퍼로 반복 재생합니다.
- 첫 터치에 재생을 시작하고 다른 앱·탭으로 이동하면 멈춥니다. 복귀 시 이어서 재생하며 수동 일시정지는 유지합니다.
- HTML 오디오 재생과 Media Session API를 사용하지 않습니다. 효과음과 하나의 AudioContext를 공유합니다.
- 음악·음량·효과음 설정과 기존 정원 기록을 보존합니다.
- 효과음은 첫 입력 때 59개 버퍼를 미리 준비하고 재사용합니다.

BGM: **BEATWAVE · James K**. 보컬 트랙을 제외한 악기 stem으로 만든 약 56초 모노 루프입니다.

시작 화면 배너와 결과 화면 선택형 보상 광고는 미리보기입니다. 실제 광고 SDK·광고 요청·보상 지급은 연결하지 않았습니다.

## 확인 범위

관련 자동 검사 52개 통과. Chrome의 Web Audio 버퍼·효과음 병행·중단/복귀 및 실제 게임 설정을 확인했습니다. 효과음 사전 준비를 포함한 공개 v26에서도 음악 재생 상태·효과음 버튼·HTML 미디어 요소 0개·오류 로그 0개를 확인했습니다.
**대표님 iPhone Safari 및 토스 앱 내 잠금 화면/제어 센터의 지금 재생 중 표시, 효과음 누락은 확인 못 함.** Chrome 검증은 이 항목의 통과 근거가 아닙니다.

진행과 설정은 해당 브라우저에 저장됩니다. 브라우저 데이터 삭제 시 사라질 수 있으며 기기 간 동기화는 제공하지 않습니다. 기존 버전 2–6 정원은 기존 규칙을 유지합니다.
