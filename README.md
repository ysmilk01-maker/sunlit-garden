# 햇빛정원

[v27 테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261020-27)

로그인 없이 즐기는 세로 화면 정원 퍼즐입니다. 씨앗을 배치하고 7일의 수확 목표에 도전합니다. 개발 테스트판이며 정식 판매 버전이 아닙니다.

## 세 가지 정원 설계

새 정원은 꿀벌의 정원·달빛 버섯숲·무지개 화원 중 하나를 고릅니다.

| 설계 | 조건 | 1·2·3단계 조건 |
|---|---|---|
| 꿀벌의 정원 | 벌집 옆에 놓인 서로 다른 꽃 칸 | 2·4·6칸 |
| 달빛 버섯숲 | 상하좌우에 빈 땅이 남은 버섯 | 1·2·3개 |
| 무지개 화원 | 정원에 심은 서로 다른 식물 종류 | 3·4·6종 |

설계 1·2·3단계의 추가 햇살은 **한 번 수확할 때 정원 전체 합계 +4·+10·+18**입니다. 식물 한 개마다 붙는 값이나 단계를 더한 누적값이 아닙니다. 조건에 맞는 대상에 나누어 반영됩니다.

- 새 버전 8 정원에만 설계가 적용됩니다. 기존 버전 2–7 진행은 당시 규칙으로 이어갑니다.
- 7일 길이와 기존 단계의 수확 목표는 유지합니다.
- 설계를 고르면 첫 씨앗 선택에 관련 재료가 나옵니다. 이후에는 일반 씨앗 선택이 이어집니다.
- 정원을 클리어하고 마지막 수확의 설계 단계가 1 이상이면 이 브라우저의 설계 수첩에 수집됩니다.
- 설계 단계 0으로 클리어하면 점수 기록만 남고 수집은 해금되지 않습니다. 최고 단계와 최고 점수는 각각 보관합니다.

## 음악과 저장

약 56초의 BEATWAVE 연주곡을 기존 Web Audio 버퍼 방식으로 반복 재생합니다. 음악·효과음·음량 설정과 기존 진행을 보존합니다. BGM: **BEATWAVE · James K**.

진행과 수집 기록은 해당 브라우저에 저장됩니다. 브라우저 데이터 삭제 시 사라질 수 있으며 기기 간 동기화는 제공하지 않습니다. 시작 화면 배너와 결과 화면 광고는 미리보기이며 실제 광고 SDK·요청·보상 지급은 연결하지 않았습니다.
