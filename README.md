# 햇빛정원 · 백 개의 정원

[아이폰 Safari에서 테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261013-6)

로그인 없이 실행하는 개발 중인 세로 화면 정원 게임입니다.

- 100개 단계에서 최소 점수 목표에 도전합니다. 12종 식물과 시설을 활용하며 정원은 4×4에서 최대 7×7로 커집니다.
- 토끼 모모가 게임 속 2·4·6일에 미션을 제안합니다. 같은 단계·같은 날 미션 첫 해결 시 꽃잎 2개, 단계 첫 클리어 시 꽃잎 3개를 받습니다.
- 꽃잎으로 장식 4종을 열고 정원에 적용합니다. 장식을 적용해도 꽃잎은 줄지 않습니다.
- 단계별 별 평가와 수집 기록을 확인합니다. 기존 캠페인 기록은 새 프로필에 반영합니다.
- 소리·진동 설정을 제공합니다. iPhone Safari는 진동을 지원하지 않습니다.
- 세로 화면 전용입니다. 휴대폰을 가로로 돌리면 세로 전환 안내를 표시합니다.
- 진행 기록은 해당 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터 삭제 시 기록이 사라질 수 있습니다.

현재 테스트판입니다. 실제 iPhone Safari의 전체 화면·저장·음향 동작은 실기기에서 별도 검증이 필요합니다. 유료 완제품이나 앱 스토어 출시본이 아니며, 재미·난이도·구매 의향 역시 추가 검증 대상입니다.

## 로컬 실행

이 저장소 폴더에서 Python 3으로 정적 서버를 실행합니다.

```sh
python -m http.server 8796 --bind 127.0.0.1
```

같은 컴퓨터의 브라우저에서 `http://127.0.0.1:8796/`을 엽니다. 다른 기기에서는 위 공개 테스트 링크를 사용합니다.

현재 화면은 `experience-app.mjs`, 미션·장식·별 기록은 `garden-features.mjs`, 캠페인 규칙은 `campaign-core.mjs`를 사용합니다. 이전 모듈은 기록과 공유 데이터 의존성을 위해 유지합니다.

원본 게임 로직과 디자인은 나인투식스랩의 프로젝트입니다. 별도 이용 허가를 부여하지 않습니다.
