# 햇빛정원 — v30 주문 정원

[테스트 플레이](https://ysmilk01-maker.github.io/sunlit-garden/?v=20261026-30)

식물 네 종류로 이웃의 주문을 완성하는 세로 화면 정원 게임입니다. 개발 테스트판입니다.

- 5×5 정원에서 하루 행동 3번을 심기·물 주기·옮기기·뽑기에 나눠 씁니다.
- 다 자란 식물이 주문 배치를 만족하면 납품합니다. 수확한 식물은 사라지고 땅을 다시 쓸 수 있습니다.
- 해바라기·꽃다발·버섯·라벤더 주문은 도장 1개, 꿀 주문은 2개이며 벌집을 남깁니다.
- 납품 보상으로 오늘 행동 1번 또는 보관할 영양제를 선택합니다. 하루 한 번 주문 교체 가능.
- 첫 정원은 10일 안에 도장 5개. 다음 정원은 목표가 1개씩 늘어 최대 8개입니다.
- 이전 점수 정원은 [이전 게임](./classic.html?v=20261026-29)에서 그대로 이어갑니다. 저장 키를 분리해 기존 기록을 보존합니다.

자동 검사 380개 통과. Chrome 모바일 크기 조작 확인. 실제 iPhone Safari·사람의 재미 및 장기 밸런스는 확인 못 함.
광고·결제는 연결하지 않았습니다. 기존 Web Audio 배경음악과 효과음을 재사용합니다.
게임·디자인·음악 자산은 나인투식스랩 프로젝트 자산이며 별도 이용 허가를 부여하지 않습니다.
